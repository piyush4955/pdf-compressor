# PDF Compressor

A modern web application that allows users to compress PDF files directly in the browser without uploading them to any server. This project is built using vanilla HTML, CSS, and JavaScript.

## Features

- **Client-side PDF compression** - All processing happens in your browser
- **Drag and drop** file upload functionality
- **Multiple compression levels** - Low, medium, and high compression options
- **Progress indicators** - Visual feedback during compression
- **Responsive design** - Works on desktop and mobile devices
- **Dark/Light mode** - Toggle between themes
- **No server uploads** - Your files never leave your computer

## Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- Vanilla JavaScript
- PDF.js for PDF processing
- Font Awesome for icons
- Google Fonts (Poppins)

## How to Use

1. Open `index.html` in a modern web browser
2. Drag and drop a PDF file or click to browse files
3. Select your preferred compression level
4. Click "Compress PDF"
5. Download your compressed PDF file
